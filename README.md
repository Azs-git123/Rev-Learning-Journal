# Reverse Engineering Learning Journal

## Deskripsi

Repository ini berisi dokumentasi perjalanan belajar Reverse Engineering selama satu semester. Setiap catatan ditulis berdasarkan materi yang dipelajari, praktik yang dilakukan, serta refleksi pribadi selama proses pembelajaran.

## Tujuan

* Mendokumentasikan proses belajar secara konsisten.
* Membangun kebiasaan menulis dokumentasi teknis.
* Memahami konsep dasar Reverse Engineering.

## Catatan

Repository ini akan diperbarui secara berkala selama proses perkuliahan berlangsung. Seluruh isi repository merupakan hasil pembelajaran dan praktik pribadi.
